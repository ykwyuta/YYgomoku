# ならびがみえる五目ならべ

スマホで遊べる、**はじめての子どもでも遊べる**五目ならべです。
置く前に「置いたらどうなるか」（五・四・いきた三・四三…）が見え、かてる点・ふさがないと負ける点・あぶない点が盤に光るので、打ちながら覚えられます。

[いきがみえる囲碁（YYigo）](https://github.com/ykwyuta/YYigo) と同じ考え方・同じ構成で作っています。ブラウザだけで動く静的サイトです。ビルドもサーバーも要りません。Cloudflare（Workers の静的アセット配信）でそのまま公開できます。

- **2つのルール**
  - **じゆう**：たて・よこ・ななめに 5つ以上 ならべたら かち。はじめての子ども向け
  - **れんじゅ**：くろは ちょうど 5つで かち。くろだけ 三三・四四・長連（6つ以上）が きんじて
- 盤の大きさ：9路・13路・15路・19路
- CPU 対戦（はじめて／よわい／ふつう／つよい、くろ・しろ・おまかせ）。「はじめて」は 5つ ならべられるときは ほぼ必ず ならべますが、あいての四を半分くらい見のがし、半分以上の手を適当に打つので、子どもでも勝てます
- ふたりで対戦（1台のスマホを交互に使う）
- **つめごもく もんだい 30 問**（1手 10・3手 10・5手 10）。全問に解説つき
- 対局は自動保存。ブラウザを閉じても続きから遊べます
- ホーム画面に追加するとアプリのように全画面で使えます

## 子ども向けのおたすけ機能

| 機能 | 内容 |
| --- | --- |
| おく前に たしかめる | 空いている点をタッチすると、うすい石と「置いたらどうなるか」（五・いきた四・四四・四三・三三・四・いきた三、あいての四や三を ふさいだか）を表示。もう一度タッチで置きます（せっていで 1回タッチに変更可）。 |
| ならびが見える | 石をタッチすると、その石から のびる 4つの向きの ならびが光り、それぞれ いくつ ならんでいるか・どんな形か（いきた三 など）を表示します。 |
| ならびの かず | 3つ・4つ ならんだ石（まだ 5つに のばせるもの）に数字。4 は赤く点滅します。 |
| かてる ところ | 置くと 5つ ならぶ点に 緑の わ。 |
| ふさがないと まける ところ | あいてが次に 5つ ならべる点に 赤い わ。画面も「あぶない！」と知らせます。 |
| あぶない ところ | あいてに置かれると ふせげなくなる点（いきた三の はし など）に「!」。 |
| きんじて | れんじゅで くろの番のとき、置けない点に「×」。タッチすると 三三・四四・長連 の理由を説明します。 |
| 四・三のお知らせ | 四や いきた三ができると「四！」「いきた三！」と表示。CPU が作ったときは赤く知らせます。 |
| ヒント | CPU がおすすめの手を教えてくれます（光った点をタッチするだけ）。 |
| まった | 何手でも戻せます。負けた後でも「まった」で戻ってやり直せます。 |

「ルール」ボタンでは、石の置き方・五・四・いきた四・いきた三・とびの三と四・四三・ふせぐ・れんじゅの きんじて・ひきわけ を図つきで説明します。

## つめごもく もんだい

画面上の「つめごもく」ボタン（またはメニュー）から、30 問の問題集を遊べます（じゆうルール・9路）。

- くろの番。決められた手数で 5つ ならべます。
- しろは いちばん長く ふせぐ手を打ってきます。
- 手数内に 5つ ならべられない手を打つと、しろに ふせがれて「ざんねん」。「まった」で戻ってやり直せます。
- 「ヒント」で次の正解の手が光ります。「こたえを みる」で解説・まちがえやすい手（とその ふせぎ方）を見たり、正解手順を盤に並べたりできます。
- クリアした問題には ★ が付き、記録は自動保存されます。

| 手数 | 内容 |
| --- | --- |
| 1手 | 五を つくる（よこ・たて・ななめ・へり・とびの四、あいてにも四がある形） |
| 3手 | いきた四・四四 |
| 5手 | 三三・四三・ふせげない三 |

### 問題の作り方と検証

1手問題のいくつかと 3手の 四四 は手で作りました。そのほかは `tools/gen-tsumego.js` で、CPU 同士（よわい）がランダムに打った局面から候補を作り、ソルバー（`js/tsumego.js`）で次の条件を満たすものだけを残して、正解に関係のない石を取り除いてから選び、解説を書いています。

- ちょうど N 手で かてて、それより短い手数では かてない
- 初手の正解がひとつだけ（くろの すべての空き点を調べる）。しろが どの いちばん長い受けを選んでも、くろの正解はいつもひとつ
- まだ どちらも 5つ ならんでいない

ソルバーは、しろは盤の すべての空き点を、くろは「五の点・しろの四をふさぐ点・5マスの中に くろが 3つ（残り 2回なら 4つ）以上 そろう点」を読み切ります。`node test/tsumego.test.js` で全問を確かめています。

```sh
node tools/gen-tsumego.js 5 10 13 > candidates.json   # 5手問題の候補を 10 個（seed 13・9路）
```

## ルール

- 黒と白が交互に、線の交わる点に石を置きます。くろが先。置いた石は動かせず、取られることもありません。
- たて・よこ・ななめの どれかに 自分の石を 5つ つづけて ならべた方の勝ち。
- じゆう：6つ以上ならんでも勝ち。きんじて なし。
- れんじゅ：くろは ちょうど 5つで勝ち。くろだけ、三三（いきた三が 2つ同時）・四四（四が 2つ同時。一直線の四四もふくむ）・長連（6つ以上）になる点には置けません。ただし 5つが できるときは置けます。三三の「三」は、四にする点が きんじてでない「本当の三」だけを数えます。しろは 5つ以上で勝ち、きんじて なし。
- 盤が全部うまったら引き分け。

## 遊びかた

1. 石を置きたい点をタッチ。うすい石と、置いたらどうなるかが出ます。
2. もう一度タッチすると置きます。
3. 石をタッチすると「ならび」が見えます。4 が出たら あと 1つ！
4. 赤い わ が出たら すぐ ふさごう。迷ったら「ヒント」、間違えたら「まった」。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要で、静的ファイルへのリクエストは無料プランでも無料・無制限です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. ゲーム本体と `wrangler.jsonc` が入ったブランチを、Cloudflare がビルドする本番ブランチにしておく（このリポジトリの既定ブランチは `master`。ここにマージするか、Cloudflare 側の本番ブランチを変更する）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログイン（無料アカウントで OK）→ **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYgomoku` を選ぶ。
4. 設定はそのままで構いません。
   - ビルドコマンド：空欄
   - デプロイコマンド：`npx wrangler deploy`（既定値）
   - ルートディレクトリ：`/`
5. **デプロイ** を押すと `https://yygomoku.<あなたのサブドメイン>.workers.dev` で公開されます。

以降は本番ブランチに push するたびに自動で再デプロイされます。

> **`Could not detect a directory containing static files` で失敗する場合**
> Cloudflare がビルドしたブランチに `wrangler.jsonc` が入っていません（README だけの `master` をビルドしたときなど）。ゲームを含むブランチをマージするか、Worker の **設定 → ビルド → ブランチ管理** で本番ブランチを切り替えてから再デプロイしてください。

### 方法 B：手元のパソコンからコマンドで公開

```sh
npx wrangler login    # 初回のみ。ブラウザで Cloudflare にログイン
npx wrangler deploy   # 公開（URL が表示される）
```

公開前に手元で確認したいときは `npx wrangler dev` で http://localhost:8787 に立ち上がります。

### 公開に関係するファイル

| ファイル | 役割 |
| --- | --- |
| `wrangler.jsonc` | Worker 名（`yygomoku`）と、リポジトリのルートを静的サイトとして配信する設定。 |
| `.assetsignore` | 公開しないファイル（README・テスト・設定ファイルなど）。 |
| `_headers` | キャッシュとセキュリティ関連の HTTP ヘッダー。 |

## ファイル構成

```
index.html             画面
css/style.css          見た目（スマホ縦向きを基本に、広い画面では2段組み）
js/rules.js            ルールエンジン（着手・五の判定・線の形の判定・れんじゅの きんじて）
js/ai.js               CPU 思考（形による手の見つもり・四を つづけて かつ VCF・アルファベータ探索。制限時間で打ち切り）
js/worker.js           CPU の思考を Web Worker で動かす（画面が固まらない）
js/tsumego.js          つめごもく もんだいのソルバー（正解判定・しろの受け・ヒント・まちがえやすい手）
js/tsumego-data.js     つめごもく もんだい 30 問と解説
js/ui.js               描画と操作（おたすけ表示・ヒント・まった・保存）
manifest.webmanifest   ホーム画面に追加したときの設定
icons/                 アイコン
test/                  Node.js で動くテスト（公開はされない）
tools/                 問題の生成ツール（公開はされない）
```

ルールエンジンは DOM に依存しない純粋な関数で、`apply` は常に新しい局面を返します。1本の線の形（五・いきた四・四・いきた三・三・二）は、置いた点のまわり 11 マスを 3 進数の番号にして表にためておくので、CPU もおたすけ表示も同じ判定を高速に使えます。`index.html` をファイルとして直接開いた場合など Web Worker が使えない環境では、CPU は画面側で考えます。

```js
require('./js/rules.js'); require('./js/ai.js');
let s = Engine.newGame({ size: 15, rule: 'renju' });
s = Engine.apply(s, AI.think({ size: s.size, board: s.board, turn: s.turn, rule: s.rule }, 'normal'));
console.log(s.kifu); // [ '●8の八' ] など
```
